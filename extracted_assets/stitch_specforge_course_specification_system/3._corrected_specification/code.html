Course Summary

auto_awesome edited by AI: Clarified prerequisites and core concepts
This course provides a comprehensive rigorous foundation in modern data structures, abstract data types, and algorithmic analysis. Students formulate, implement, and benchmark canonical arrangements including dynamic collections, binary balanced trees, heaps, and graph networks. Special emphasis is placed on asymptotic complexity quantification (Big-O, Big-Omega notation), recursion invariant verification, and standard memory management paradigms for large-scale computational problem solving.

Course Contents (45 Total Lecture Hours)

tune AI marker: Rebalanced Unit 3 hours
UNIT I •

Asymptotic Analysis, Arrays, Stacks & Queues

Order of growth analysis, Master Theorem, dynamic array doubling, amortized complexity, doubly linked chains, circular buffers, stack evaluation of expressions.

9 Hours
UNIT II •

Trees, Heaps, and Priority Queues

Binary search trees, AVL rotations, Red-Black balancing invariants, binary heaps, leftist heaps, Huffman coding trees, tree serializations.

9 Hours
UNIT III •

Hashing and Disjoint Sets

Updated 8 hrs

Universal hash families, separate chaining, open addressing with quadratic probing & double hashing, cuckoo hashing, union-find with path compression.

8 Hours
UNIT IV •

Graph Algorithms and Connectivity

Breadth-first search, depth-first search, topological sort, strongly connected components (Kosaraju & Tarjan), minimum spanning trees (Kruskal, Prim), Dijkstra & Bellman-Ford shortest paths.

9 Hours
UNIT V •

Algorithm Design Paradigms & Tractability

Divide and conquer, dynamic programming (knapsack, matrix chain multiplication), greedy heuristics, branch and bound, introduction to NP-completeness and reductions.

10 Hours
